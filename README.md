# Tenique Pedidos — instaladores

Aquí se publican los instaladores de **Tenique Pedidos**, el programa de Windows con el que los
restaurantes reciben, aceptan e imprimen sus pedidos de delivery.

- **Descargar:** [última versión](https://github.com/fynaltgn/tenique-pedidos-releases/releases/latest) → `TeniquePedidos-Setup-X.Y.Z.exe`
- Una vez instalado, **se actualiza solo**.
- Para usarlo hace falta la API key que Tenique da a cada restaurante.

Este repositorio no contiene código fuente.
